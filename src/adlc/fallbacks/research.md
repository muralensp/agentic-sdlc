Answer a question from primary sources and save the findings. Write no code.

1. State the question in one sentence.
2. Use official documentation, specifications, source code and release notes. Avoid blogs and answers without a source.
3. Check the version you are reading against the version the project uses.
4. Write docs/research/<topic>.md: the question, the answer first, then the evidence with a link and a date for each claim, then what is still unknown.
5. Mark anything you could not verify as unverified instead of guessing.
