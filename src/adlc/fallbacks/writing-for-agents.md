Write the files agents always load (AGENTS.md, CLAUDE.md, project skills) so they stay useful.

1. Keep them short, within the repository's line limit. Anything long belongs in a linked document.
2. Use headings and bullets. Give commands exactly as they are run.
3. Point to ADRs, the glossary and the logs instead of copying them.
4. State rules as things to do or not do, with the reason in a few words.
5. Remove anything that is out of date or that the code already shows.
