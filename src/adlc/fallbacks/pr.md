Write the pull request description for a reader who has not seen the work.

1. Use the repository's PR template if there is one.
2. Say what changed and why, in a few lines. Link the work item.
3. List the evidence: which checks ran, with real results, and anything you did not verify.
4. Call out risks, follow-ups and decisions a reviewer should look at.
5. Do not paste long logs; link to them.
